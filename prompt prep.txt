## Key Decisions
- **Load mods in `Game.Initialize()` before `SceneSystem`** — avoids mid-frame SceneInstance replacement which causes Material.New() effects to not compile and VisibilityGroup timing issues
- **Don't replace SceneInstance** — creating a new SceneInstance mid-frame breaks effect compilation because the EffectSystem cache is cold and shader sources aren't found through DatabaseFileProvider
- **Eager VisibilityGroup in SceneInstance setter** — ensures render processors exist before first draw
- **Manual CameraProcessor.Draw() call** — bypasses normal Draw phase timing to attach camera to compositor slot before first render
- **ModSceneManager for runtime switching** — deferred to end-of-frame via ModSceneSwitchSystem to avoid mid-frame issues
- **ModSceneEntry in Stride.Engine.Modding** — test dependency requires this class to exist in this namespace
